# 3D 카메라와 투영

> OpenGL에서 사용하는 `glm::lookAt` 과 `glm::perspective` 는 선형대수의 핵심 개념인 행렬을 바탕으로 3D 카메라와 투영을 다루는 함수

## Intro

*OpenGL* 에서 **한 정점(Vertex)** 이 화면에 찍히기까지는 다음 순서를 거침

```
모델 공간(Model Space)
      ↓
월드 공간(World Space)
      ↓
뷰 공간(View Space)
      ↓
클립 공간(Clip Space)
      ↓
화면 공간(Screen Space)
```

| 단계          | 행렬                                     | 역할           |
| ----------- | -------------------------------------- | ------------ |
| 모델 -> 월드     | `model`                                | 오브젝트를 공간에 배치 |
| 월드 -> 카메라(뷰) | `view` = `glm::lookAt(...)`            | 카메라 좌표계로 변환  |
| 카메라 -> 클립    | `projection` = `glm::perspective(...)` | 원근감 있는 투영    |

## `glm::lookAt(...)` : 카메라(View) 행렬

<p align="center">
    <img src="https://learnopengl.com/img/getting-started/camera_axes.png" alt="Example Image" width="60%">
    <br/>
    이미지 출처: learnopengl.com
</p>

- **개념**

   카메라가 **어디에서 어디를 바라보는지** , **어디를 위로 둘지** 정의해서 **월드 공간을 카메라 공간으로 바꾸는** 행렬을 생성하는 함수

   ```cpp
   glm::mat4 lookAt(glm::vec3 eye, glm::vec3 center, glm::vec3 up);
   ```

   - `eye` : *카메라 위치 (어디서 보는지)*

   - `center` : *카메라가 바라보는 위치*

   - `up` : 카메라의 **"위쪽"** 방향 (보통 `glm::vec3(0, 1, 0)`)

   ---

- **행렬 관점**

   1. **카메라 방향 벡터**

      ```cpp
      z = normalize(eye - center); // 뒤쪽을 바라보는 방향
      ```

      ---

    2. **카메라의 오른쪽 벡터**

       ```cpp
       x = normalize(cross(up, z));
       ```

       ---

    3. **카메라의 위쪽 벡터**

       ```cpp
       y = cross(z, x);
       ```

       ---

    이 세 벡터는 **카메라의 좌표계(축)** 를 정의

    `lookAt` 은 다음과 같은 뷰 변환 행렬을 반환

    ```
    | x.x  x.y  x.z  -dot(x, eye) |
    | y.x  y.y  y.z  -dot(y, eye) |
    | z.x  z.y  z.z  -dot(z, eye) |
    |  0    0    0        1       |
    ```

    즉, 모든 Vertex가 카메라 기준으로 이동하게 됨

    ---

## glm::perspective(...) : Projection 행렬

<p align="center">
    <img src="https://learnopengl.com/img/getting-started/perspective.png" alt="Example Image" width="60%">
    <br/>
    이미지 출처: learnopengl.com
</p>

- **개념**

   3D 공간을 2D 화면에 투영하면서 원근감을 표현하기 위한 변환

   ```cpp
   glm::perspective(glm::radians(fov), float aspect, float near, float far);
   ```

   - `fov` : *수직 시야각 (Field of View, in radians)*

   - `aspect` : *종횡비 (width / height)*

   - `near` , `far` : *클립 범위*

   ---

- **행렬 관점**

   3D 공간의 정점을 클립 공간으로 보내는 투영 행렬을 만듬

   z축 방향으로 멀어지는 정점이 더 작아지는 효과, 즉 **원근 투영(perspective projection)**


   $$
   P_{persp} =
   \begin{bmatrix}
   \frac{1}{\tan(\frac{fov}{2}) \cdot aspect} & 0 & 0 & 0 \\
   0 & \frac{1}{\tan(\frac{fov}{2})} & 0 & 0 \\
   0 & 0 & \frac{f+n}{n-f} & \frac{2fn}{n-f} \\
   0 & 0 & -1 & 0
   \end{bmatrix}
   $$

   - *가까운 물체는 크게 표현*

   - *멀리 있는 물체는 작게 표현*

   ---

## 요약

| 항목    | `lookAt`       | `perspective`   |
| ----- | -------------- | --------------- |
| 목적    | 월드 공간 → 카메라 공간 | 카메라 공간 → 클립 공간  |
| 본질    | 좌표계 변환         | 투영 변환           |
| 영향    | 카메라 방향과 위치     | 시야각, 원근감        |
| 사용 위치 | `view` 행렬      | `projection` 행렬 |
